# WMSU Europe

**WORK MOVE SIMPLIFY UNIFY — A Better Union Research Project**

An independent European research project examining how people work, find employment, move and connect across national borders.

Website: https://wmsu-europe.github.io/

## Research themes

- Starting work across the EU: formal rights and practical access to employment.
- Finding work across borders: job seeking, recruitment and opportunities.
- Cross-border rail connections.
- Language and access to services.
- Telecommunications and everyday connectivity.

The website distinguishes ongoing research from themes in development. Research descriptions are not statements of completed findings.

## Website files

This is a static HTML, CSS and JavaScript website, published with GitHub Pages. `index.html` is the home page. `styles.css` controls the presentation, `app.js` provides navigation and research-panel interactions, and `site-config.js` holds the author link and future PDF slots. `.nojekyll` keeps the static files intact.

To add a project PDF, place it under `assets/documents/` and replace the corresponding `null` in `site-config.js` with its relative path. Commit the changes to update the published website.
